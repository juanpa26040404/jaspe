# Jaspe · Joyería en oro y plata

Sitio de una sola página: `index.html` lleva todo incrustado (fotos, fuentes, ícono de WhatsApp).

- Publicación: Netlify, a partir de este repositorio (rama `main`, carpeta raíz).
- Configuración del sitio: al inicio del `<script>` de `index.html`, en `CONFIG` (WhatsApp, márgenes, costos por gramo, GA4, píxel de Meta, Supabase).
- `logo/`: logotipo en SVG y PNG.
